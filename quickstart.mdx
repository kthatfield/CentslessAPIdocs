---
title: "Quickstart"
description: "Confirm the API is reachable, process one cash transaction, and read the evidence it returns."
---

This walkthrough takes about five minutes. You need an API key; see [Authentication](/authentication) for how keys are issued.

<Steps>
  <Step title="Confirm the API is reachable">
    The health endpoint needs no key.

    ```bash
    curl https://api.centsless.org/api/v1/health
    ```

    The response names the API version, the engine version, the dataset version, and how many enacted states the engine has loaded.

    ```json
    {
      "status": "healthy",
      "version": "3.8.0",
      "engine_version": "1.4.0",
      "dataset_version": "2026.10.25-r2",
      "features": {
        "jurisdiction_service": {
          "enacted_states": 23,
          "federal_status": "default_practice",
          "pending_effective": 7
        }
      }
    }
    ```
  </Step>

  <Step title="Ask which rule governs a location today">
    Jurisdiction lookups need no key either. This asks what governs a retail cash sale in Raleigh, North Carolina, today.

    ```bash
    curl "https://api.centsless.org/api/v1/jurisdiction/zip/27601?transaction_type=retail"
    ```

    The important fields are `rounding_mode`, `obligation`, `activation.state`, and `statutory_basis`.

    ```json
    {
      "lookup_key": "NC",
      "jurisdiction_level": "state",
      "rounding_mode": "symmetrical_rounding",
      "obligation": "permits",
      "legislation": "SB 595",
      "citation": "N.C.G.S. 66-515; 18B-804A; 105-357(a1)",
      "tier": { "tier_id": "NC-RETAIL", "citation": "N.C.G.S. 66-515 (S.L. 2026-31, s. 14.(a))" },
      "activation": {
        "state": "in_force",
        "governs": true,
        "local_transaction_date": "2026-10-25",
        "effective_date": "2026-07-02"
      },
      "pending_rules": []
    }
    ```

    Change `transaction_type=retail` to `transaction_type=tax_payment` and the same ZIP resolves to a different rule: N.C.G.S. 105-357(a1), which obligates taxing units to round in-person cash tax payments down.
  </Step>

  <Step title="Process a cash transaction">
    Send the pre-tax subtotal and the tax in cents, the tender, and the location. Amounts are always integers in cents.

    ```bash
    curl -X POST https://api.centsless.org/api/v1/transaction \
      -H "x-api-key: $CENTSLESS_API_KEY" \
      -H "content-type: application/json" \
      -d '{
        "merchant_id": "RALEIGH-HARDWARE-01",
        "terminal_id": "REG-2",
        "subtotal_cents": 1000,
        "tax_total_cents": 73,
        "payment_method": "cash",
        "zip_code": "27601",
        "transaction_timestamp": "2026-10-25T14:05:00-04:00"
      }'
    ```

    The ledger total is $10.73. North Carolina permits symmetrical rounding to the nearest five cents, so the cash total is $10.75 and the delta is two cents.

    ```json
    {
      "success": true,
      "transaction": {
        "id": "TXN-2026-10-25-8F360056",
        "calculation": {
          "ledger_total_cents": 1073,
          "cash_total_cents": 1075,
          "rounding_delta_cents": 2,
          "rounding_applied": true,
          "cash_rounding_mode": "symmetrical_rounding",
          "jurisdiction": "US-NC",
          "jurisdiction_status": "enacted",
          "jurisdiction_legislation": "SB 595",
          "jurisdiction_obligation": "permits",
          "activation_state": "in_force"
        },
        "statutory_basis": {
          "legislation": "SB 595",
          "session_law": "Session Law 2026-31, Part XIV",
          "citation": "N.C.G.S. 66-515; 18B-804A; 105-357(a1)",
          "status": "enacted",
          "activation_state": "in_force",
          "tier_id": "NC-RETAIL",
          "local_transaction_date": "2026-10-25",
          "local_date_source": "sender_offset",
          "dataset_version": "2026.10.25-r2"
        },
        "auditHash": "7f3c…",
        "previousHash": "a91e…",
        "chainPosition": 85
      }
    }
    ```
  </Step>

  <Step title="Read the evidence">
    Every transaction can be retrieved by id, and a receipt can be rendered in three formats.

    ```bash
    curl "https://api.centsless.org/api/v1/transaction/TXN-2026-10-25-8F360056/receipt?format=audit" \
      -H "x-api-key: $CENTSLESS_API_KEY"
    ```

    The `audit` format includes the hash chain position, the statutory basis, and the fraud score. The `merchant` format is customer-facing with a rounding disclosure. The `pos` format is raw cents only.
  </Step>
</Steps>

<Warning>
Send `x-api-key` as a request header. Placing it in the query string sends the key in the URL, which is logged by proxies, and the request is rejected as unauthenticated.
</Warning>
